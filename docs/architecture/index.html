② 데이터 흐름도

읽기(최초 로드)와 쓰기(생성·수정·삭제) 양방향 데이터 흐름입니다. 모든 흐름은 NotesContext를 거치며, 낙관적 업데이트 없이 API 응답을 받은 뒤 notes 상태를 갱신합니다.

③ 상태 흐름도

앱 화면의 상태 전이입니다. 데이터 로딩 상태(NotesContext의 loading/error)와 에디터 화면 상태(App.tsx의 selectedNoteId · isCreating 조합)를 상태 머신으로 표현합니다. 

stateDiagram-v2
    [*] --> 로딩중
    로딩중 --> 오류: fetchNotes 실패
    로딩중 --> 빈화면: fetchNotes 성공

    note right of 빈화면
      selectedNoteId = null
      isCreating = false
    end note

    빈화면 --> 작성중: + 새 노트
    빈화면 --> 편집중: 노트 선택

    작성중 --> 빈화면: 저장(생성) / 취소
    작성중 --> 편집중: 사이드바 노트 선택

    편집중 --> 작성중: + 새 노트
    편집중 --> 편집중: 저장(수정) / 다른 노트 선택
    편집중 --> 빈화면: 선택 노트 삭제

    note left of 작성중
      isCreating = true
    end note
    note right of 편집중
      selectedNoteId 설정됨
      isCreating = false
    end note
